Data Science: learning from data

Exam prep built from Lectures 1–5, including the handwritten notes on perceptrons and Hoeffding.

1. What is learning from data?

Raw data plus metadata (data that describes the data, e.g. column names) gives information. A table of numbers means nothing until each column has a name.

Knowledge is a specific pattern that is not written explicitly in the data. The information is not handed to you: you go looking for it. A model learns by reading many events and extracting the pattern behind them.

Analogy. A table of daily temperatures is information. “It gets hotter every June” is knowledge: nobody wrote it in a cell, you found it.

Why mathematics?

To say what a pattern is, we need a generic formulation: a mathematical formula is the best way to represent an abstraction. Geometry example: plot points, then search for the equation of the circle to learn what controls the shape. When a problem gets complex, mathematical rules let us extract the knowledge.

2. Equations as hypotheses

The slope (how many bends the data has) decides the polynomial degree. The learning process means tuning the slope and the coefficients.

y = a₁x⁴ + a₂x³ + a₃x² + a₄x + b

Example: salary (y) vs years of experience (x) can wiggle, so it needs a higher degree. A logistic equation gives a bounded S-shaped curve instead. A word problem becomes useful once you turn it into an equation: that is how you obtain knowledge that was not there before.

Also noted: an empty result set means the record is null.

4. Separating classes with a line

The decision is made mathematically. Points on the line evaluate to zero. The rule is a straight line with a specific slope, and the attributes of the data tell us where it goes. Each side is a signature of a class: + for one, − for the other. They are only labels. + does not mean “good” and − does not mean “bad”.

Vectors and lines

A vector has a direction. Any point defines a line through the +ve direction, and the vector is the slope of the line.

y = mx + c, m = Δy/Δx = (y₂ − y₁)/(x₂ − x₁)

Two lines with the same slope are parallel, and they are the same line only if the intercept is also equal. Each line has one vector (v₁, v₂, v₃…). The +ve direction decides whether a point is above or below the line.

x · w > 0 → +ve side | x · w < 0 → −ve side

The weights are the coefficients, and they represent the slope. A dot product (x · w) is the weight times the vector.

5. Fixing mistakes: the perceptron update

A hypothesis is a candidate line. We need a mechanism to change it so it becomes better. The rule: take one misclassified point at a time and move the line to fix it.

CaseAngle with wUpdate
True + but predicted −obtusew_new = w + x (angle shrinks)
True − but predicted +acutew_new = w − x

Combined: w ← w + yₙ·xₙ Adding two vectors gives a vector in the middle. Subtracting pushes it the other way. That is how we decide to move closer or farther. When you use the transpose (wᵀx), the sign you multiply by must be tracked carefully, which is what yₙ does.

To get more curves, raise the degree: x² gives one bend, x³ gives an S-shape.

6. Can we trust a learned hypothesis? (Lecture 5)

We want to lower the probability of a bad event: a wrong prediction on data we have never seen. The sample is a slice of the total population. The larger the sample N, the closer it is to the population, so the bad event becomes less likely.

P( |ν − μ| > ε ) ≤ 2·e^(−2ε²N)
  • ν = what we measure on the sample, μ = the true value on the population.
  • ε = tolerance, a decimal value you choose. The bound is the probability of the bad event at that tolerance.
  • The notes’ example: pick 1000 points out of 2000. The difference between g and the target f is what we try to shrink.
With M candidate hypotheses the bound becomes 2M·e^(−2ε²N). This is from the standard theory, not your notes.

Learning is approximation, never exact. We cannot know the whole population, so we can never be 100% sure. The best we get is probably approximately correct.

Trade-off. Learn the pattern without memorising the dataset. If the model only memorises, it fails on something different (overfitting). We want g to get as close to f as possible, and each hypothesis is judged by the errors it makes.

Training examples lead to a hypothesis set. Euler’s number is the exponential function: (1 + 1/n)ⁿ → e as n → ∞.

Memory aids

  • Plus → add, minus → subtract (for the update: the sign of the true label decides).
  • R-C-C: Regression = Number, Classification = Category, Clustering = Crowd (unknown groups).
  • Bigger N, smaller worry. The bound has N in the exponent, so it shrinks fast.
  • Review at 1 day, 3 days and 1 week. Test yourself on the MCQs before rereading.

Common traps

  • Information is not knowledge: knowledge is the hidden pattern.
  • Same slope means parallel, not automatically identical.
  • Larger N reduces the chance of a bad event, but it never makes it zero.
  • + and − are class labels, not value judgments.
  • The update applies to one point at a time.

Summary

Data → knowledge
  • Raw data + metadata = information
  • Knowledge = pattern not written explicitly; found by learning from many events
  • Pattern is expressed as a mathematical formulation (abstraction)
Problem types
  • Regression: continuous number
  • Classification: discrete, known classes
  • Clustering: find groups, classes unknown
Equations
  • Degree grows with the number of bends
  • Learning = tuning coefficients (weights)
  • Logistic = bounded S-curve
Perceptron
  • Line ↔ vector w; sign of x·w picks the side
  • Misclassified + → w + x; misclassified − → w − x; i.e. w + yx
  • One point at a time
Generalisation
  • P(|ν−μ|>ε) ≤ 2e^(−2ε²N)
  • Larger N → lower risk; never 100%
  • Learning = approximation; avoid memorising
  • g ≈ f
Vocabulary
  • Feasibility > Probability > Possibility in practical usefulness (possibility = maybe, but very hard)
  • e = lim (1+1/n)ⁿ
