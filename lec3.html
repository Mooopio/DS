Lines, vectors and the perceptron update

1. The problem

We have points of two classes and want a straight line that separates them. Points on one side are positive, points on the other are negative. Learning means moving the line until every point lands on its correct side.

2. Line basics

Slope (ميل / انحدار, also “regression” in the lecture’s wording) is the ratio of the change in y to the change in x: Δy / Δx. Equation: y = mx + b.
  • Same slope means the same line (in the lecture’s setup). Different slope means a different line, hence a different classification.
  • Above the line is positive, below is negative. If you stand above it, you are positive.
  • Different lines classify the same data differently. A point sent to the wrong side is misclassified.

3. Lines and points as vectors

Instead of writing the whole equation, we represent the line by one vector. A point is also a vector: its coordinates along the axes (x, y, z…) measured from the origin. In computer science the origin is conventionally zero.

Vector = direction + magnitude (“force”). A point as a vector starts at the origin and ends at the point. A line is not a vector, but the weight vector w that represents it is.

Key convention: the vector w representing a line is perpendicular to the line and points to its positive side. Tilt the line and w tilts with it, always staying at 90°.

Bias. The lecture drops the intercept b and lets the line pass through the origin (b = 0), so w alone defines it.

4. Which side is a point on? The dot product

Plug the point into the weights and look only at the sign:

wᵀx = w₁x₁ + w₂x₂ + …
> 0 positive side · < 0 negative side · = 0 exactly on the line.

Dot product means multiply matching components, then add everything. Vectors are written as columns, so the first one must be transposed (column to row) for the multiplication to be defined. It works unchanged in any number of dimensions (the lecture mentions x with 14 features).

Illustrative example (our numbers): w = (−1, 1), x = (2, −1). Then wᵀx = (−1)(2) + (1)(−1) = −3, so x is on the negative side.

Geometric meaning. The sign of wᵀx is the sign of the cosine of the angle between w and x. Angle below 90° (acute) gives positive. Angle above 90° (obtuse) gives negative.

5. Fixing a mistake: the update rule

If a point is misclassified, change w (so the line rotates). Two cases, using vector addition and subtraction:

MistakeAngle with wFixWhy
Positive point, predicted negativeobtusew_new = w + xThe sum falls between w and x, so the angle shrinks and x moves inside.
Negative point, predicted positiveacutew_new = w − xThe difference lands outside, pushing x out past 90°.

One formula. Fix the labels as y = +1 or y = −1, then both cases are w_new = w + y·x.

Interpret both figures: w moves to (1, 0), the line stays perpendicular to it, and the point now has the right sign. The “+” case is the top figure, the “−” case the bottom.

Repeat: loop over the points, update on each mistake. This is the Perceptron Learning Algorithm (the lecture calls it PLA).

6. Hypothesis vs target

The true rule f(x) (the target function) is unknown. We only guess a hypothesis h(x) and improve it using data. Data is what lets us learn, and the computer is only as clever as the person who designed the procedure.

7. When a straight line is not enough

Some data cannot be split by any line. A curve such as x² + x + b = 0 (a polynomial) can. Degree is the highest exponent. Raising the degree adds bends; a line is the degree-1 case. The lecture also notes that a linear model with many features is dimensional, while polynomial terms are treated as a part of it.

Traps. (1) w is perpendicular to the line, not along it. (2) Subtract for a negative point, add for a positive one. (3) A point with wᵀx = 0 is neither class yet. (4) The dot product needs the transpose.

Memory trigger: “Positive Pulls in (add), Negative Needs pushing (subtract).”

Summary

  • Goal: a line separating positive from negative points.
  • Slope = Δy/Δx. Same slope = same line.
  • Line as vector: w ⟂ line, pointing to the positive side. Bias dropped (line through origin).
  • Point as vector: coordinates from the origin.
  • Classify: sign of wᵀx (dot product, transpose needed).
  • Angle view: acute = positive, obtuse = negative.
  • Update: mistake on positive → w + x. Mistake on negative → w − x. Combined: w + y·x.
  • Hypothesis ≠ target; the target is unknown.
  • Non-separable data → polynomial (degree = highest exponent).
