1. Deep explanation

1.1 Big picture: the two learning styles

Supervised learning uses labeled data to predict outcomes. Unsupervised learning uses unlabeled data. A hybrid model that includes supervised learning uses both labeled and unlabeled data.

Analogy: Supervised = studying with an answer key (a teacher checks you). Unsupervised = being handed a pile of mixed Lego and sorting it by similarity with nobody telling you the categories.
1.2 Supervised learning

Definition: the ML approach defined by its use of labeled datasets to train algorithms to classify data and predict outcomes.

Pipeline (from the diagram)

Input raw data → Supervisor supplies the training data set and desired output → Algorithm → Processing → Output (separated groups).

Labelled dataset = feature columns + label (class) column

Example: leads with Location, Gender, Company size, Revenues, Number of emails (features) and Client = YES/NO (the label). Rows: UK/F/5/500000/3→NO; Ireland/F/6/600000/2→NO; UK/M/6/600000/5→YES; USA/F/10/1000000/12→YES; USA/F/3/300000/4→YES; USA/M/5/500000/7→YES; Germany/M/6/600000/1→NO.

Two methods

Classification: output is classes or categories.

  • Binary: two classes (Spam / Not spam).
  • Multiclass: many classes, exactly one is correct (the dog photo → Dog among Dog, Cat, Horse, Fish, Bird…).
  • Multi-label: several labels can be true at once (photo with a cat and a bird → Cat + Bird).

Regression: predicted output values are real numbers.

  • Simple: one continuous dependent variable predicted from a single independent variable (simple linear regression).
  • Multiple: predicted from multiple independent variables (multiple linear regression).
  • Nonlinear: relationship follows a nonlinear pattern; flexible for a wide range of functional forms.

Visual: classification draws a line separating groups; regression draws a line fitting through points.

Algorithms: SVM, Logistic Regression, Naive Bayes, Neural Networks, KNN, Random Forest (also decision trees).

1.3 Unsupervised learning

Definition: algorithms get data without labels. It is a kind of self-learning that finds previously hidden patterns in unlabeled data.

  • Clustering: find hidden patterns from similarities/differences; group items into clusters.
  • Association: find the relationship of one data item to another.
  • Dimensionality reduction: reduce the number of dimensions of the data; used for feature extraction.

Algorithms: k-means, hierarchical clustering, apriori.

1.5 Perceptron: the idea

Designed to mimic neurons in the human brain. A single perceptron is a linear classifier: it separates two groups with a line. It learns by readjusting itself using points it misclassified (on the wrong side of the line) at every time step.

Example: Dogs vs Cats with axes Speed (y) and Time spent sleeping (x). The line splits dogs (fast, sleep less) from cats.

1.6 Which side of the line? (distance and sign)

Line: Ax + By + C = 0. Distance of point (xa, ya): d = (A·xa + B·ya + C) / √(A² + B²).

  • Ax+By+C > 0 → one side (above in the slide)
  • Ax+By+C = 0 → on the line
  • Ax+By+C < 0 → other side (below)

Prediction: sgn(Ax+By+C): 1 = one group, −1 = the other. sgn(x)=1 if x>0; 0 if x=0; −1 if x<0.

Training set: points (x, y, a), where a = 1 or −1 is the true group. A point is misclassified when its a differs from the prediction.

1.7 Perceptron Learning Algorithm (PLA)

Two assumptions: (1) data is linearly separable (a hyperplane fully separates the two classes); (2) designed for binary classification (e.g. breast cancer positive/negative).

Update (for each misclassified point):

A ← A + a·x, B ← B + a·y, C ← C + a·1

With learning rate r: A ← A + r·a·x, B ← B + r·a·y, C ← C + r·a·1. r scales how much we correct per misclassified point.

Vector form: w₀ ← w₀ + a·1, w₁ ← w₁ + a·x₁, w₂ ← w₂ + a·x₂, i.e. w ← w + a·x (x₀ = 1 is the bias input).

Intuition: a wrong point “pulls” the line toward itself: add the point if its class is +1, subtract if −1.
Trap: if data is not linearly separable, the line keeps bouncing around and never halts.
1.8 Anatomy & multi-layer perceptrons

Anatomy: Inputs (x₀=1, x₁, x₂, x₃) × Weights (w₀…w₃) → summation (+) → activation function sgn() → Output.

Multi-layered perceptrons: sets of perceptrons linked together; they have non-linear activation functions, so they can handle data that is not linearly separable (input layer → hidden layers → output layer).

2. Smart summary & memory tools

High-yield summary
  • Supervised = labeled → predict → classification (categories) + regression (real numbers); known classes; has feedback.
    • Classification: binary / multiclass / multi-label
    • Regression: simple / multiple / nonlinear
  • Unsupervised = unlabeled → find hidden patterns → clustering, association, dimensionality reduction; unknown classes; no feedback.
  • Hybrid = labeled + unlabeled.
  • Perceptron = linear binary classifier, brain-neuron inspired, sgn(w·x).
  • PLA = on a mistake: w ← w + r·a·x. Needs linear separability or it never halts.
  • MLP = layers + non-linear activation → non-separable data.
Mnemonics
  • “CR” = Supervised: Classification & Regression. “CAD” = Unsupervised: Clustering, Association, Dimensionality reduction.
  • Binary = 2, Multiclass = 1 of many, Multi-label = many at once.
  • PLA: “Wrong? Nudge by a·x.” Sign of a decides direction.
  • Regression → Real numbers. Clustering → Collect similar.
Common mistakes & traps
  • k-means and apriori are unsupervised; do not list them as supervised.
  • Multi-label ≠ multiclass.
  • sgn(0) = 0, not 1.
  • Single perceptron cannot solve non-linearly-separable data (needs MLP).
  • Supervised is for prediction, unsupervised for analysis.
  • The slide’s prediction formula mixes ya/yb; the intended point is (xa, ya).
